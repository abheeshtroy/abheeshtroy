# Hey, I'm Abheesht 👋

I'm a software engineer based in San Francisco. I enjoy building products, exploring new ideas, and working on interesting engineering problems.

### Some things I've built

**[BehaviorDiff](https://github.com/abheeshtroy/BehaviorDiff)** — An open-source differential testing tool that compares application behavior before and after code changes, including API responses, database state, and external side effects. [Website](https://behaviordiff.com/)

**[ReqStream](https://github.com/abheeshtroy/reqstream)** — A data pipeline that processes ~1.5M job postings, filters and ranks them against a structured profile, and generates tailored documents.

**[SourceTether](https://github.com/abheeshtroy/sourcetether)** — A tool for persistent coding-agent memory that tracks where memories came from and detects when the underlying source code changes. [Demo](https://sourcetether.vercel.app/)

**[Ubuntu Cloud Tooling](https://github.com/abheeshtroy/ubuntu-cloud-tooling)** — A Python CLI for configuring Ubuntu environments using declarative YAML, repeatable operations, and automated verification.
